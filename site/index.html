Contribute a skill (5 minutes, no code required)

  1. Open a Skill proposal issue — 6 fields, done.
  2. Or paste templates/PROPOSER-PROMPT.md into any chatbot and submit the JSON.
  3. Or edit catalog/*.json directly — the factory, registry, wiki, router and CI handle the rest.

Every skill passes spec validation, strict YAML parsing, install smoke tests (Windows + Linux) and an MCP protocol test before it can merge. Contributing guide
