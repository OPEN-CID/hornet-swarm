# education

Learn anything with tutoring and study systems.

| Skill | Use it when |
|---|---|
| `chemistry-helper` | Balance equations and explain lab concepts safely. Use for chemistry homework and labs. |
| `curriculum-plan` | Design a self-study syllabus with milestones. Use when learning a subject solo. |
| `eli5-explainer` | Explain any concept simply, then rebuild to full depth in layers. Use when starting a hard topic. |
| `essay-feedback` | Critique essays for thesis, structure, and evidence. Use when revising writing. |
| `exam-prep` | Build an exam study plan with spaced practice tests. Use before any exam. |
| `exam-readiness-review` | Audit exam readiness with a timed mock and gap list. Use one week before any exam. |
| `kid-homework` | Guide kids to answers with hints, never direct solutions. Use for K-12 homework help. |
| `language-tutor` | Practice a language with corrections and drills. Use for daily speaking and writing practice. |
| `learn-playbook` | Learning-science best practices for efficient study. Use when study feels inefficient. |
| `math-tutor` | Teach math step by step with practice problems. Use when stuck on algebra through calculus. |
| `physics-tutor` | Explain physics with worked examples and unit checks. Use for mechanics and electromagnetism homework. |
| `study-doc-parse` | Turn textbook chapters or PDFs into notes, key terms, and self-test questions. Use when reading dense material. |
