# science-lab

Run trustworthy experiments and read papers well.

| Skill | Use it when |
|---|---|
| `citation-check` | Verify claims against cited sources. Use when fact-checking writing. |
| `data-analysis` | Plan analyses from question to chart to conclusion. Use for small datasets. |
| `experiment-design` | Design controlled experiments with variables and controls. Use when testing any hypothesis. |
| `lab-protocol` | Write repeatable step-by-step lab protocols. Use before bench work. |
| `paper-parse` | Extract question, method, results, and limits from papers into a structured brief. Use for literature review. |
| `paper-summarizer` | Distill papers into findings, methods, and limits. Use for literature review. |
| `research-playbook` | Reproducibility best practices for trustworthy research. Use when starting a project. |
| `result-review` | Peer-review results and analyses for errors before sharing. Use before publishing or presenting. |
| `sci-term-translate` | Translate dense paper jargon and units into plain explanations. Use when a paper is unreadable. |
| `stats-helper` | Pick the right statistical test and interpret output. Use when analyzing results. |
