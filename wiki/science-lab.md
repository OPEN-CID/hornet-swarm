# science-lab

Run trustworthy experiments and read papers well.

| Skill | Type | Use it when |
|---|---|---|
| `citation-check` | skill | Verify claims against cited sources. Use when fact-checking writing. |
| `data-analysis` | skill | Plan analyses from question to chart to conclusion. Use for small datasets. |
| `experiment-design` | skill | Design controlled experiments with variables and controls. Use when testing any hypothesis. |
| `lab-protocol` | skill | Write repeatable step-by-step lab protocols. Use before bench work. |
| `paper-parse` | skill | Extract question, method, results, and limits from papers into a structured brief. Use for literature review. |
| `paper-summarizer` | skill | Distill papers into findings, methods, and limits. Use for literature review. |
| `research-playbook` | skill | Reproducibility best practices for trustworthy research. Use when starting a project. |
| `result-review` | skill | Peer-review results and analyses for errors before sharing. Use before publishing or presenting. |
| `sci-term-translate` | skill | Translate dense paper jargon and units into plain explanations. Use when a paper is unreadable. |
| `stats-helper` | skill | Pick the right statistical test and interpret output. Use when analyzing results. |

Install: Copy-Item -Recurse skills/<name> .agents/skills/ - full file: `skills/<name>/SKILL.md`

Workflows (plays) live on the [workflows](workflows.md) page.
