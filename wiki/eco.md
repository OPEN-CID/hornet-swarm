# eco

Recycle, compost, save water, and cut carbon.

| Skill | Type | Use it when |
|---|---|---|
| `carbon-cut` | skill | Cut footprints with high-impact moves first. Use for climate action. |
| `compost-guide` | skill | Compost food scraps with browns-greens balance. Use for gardens. |
| `recycling-guide` | skill | Recycle right with local rules and sorting. Use for households. |
| `solar-evaluate` | skill | Evaluate home solar with usage math and quotes. Use before buying. |
| `sustainable-shop` | skill | Shop sustainably with labels and longevity. Use for purchases. |
| `waste-less` | skill | Cut household waste with swaps and audits. Use for lighter bins. |
| `water-save` | skill | Save water with fixture and habit fixes. Use for high bills. |

Install: Copy-Item -Recurse skills/<name> .agents/skills/ - full file: `skills/<name>/SKILL.md`

Workflows (plays) live on the [workflows](workflows.md) page.
