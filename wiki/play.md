# play

Chess, poker, game nights, and game design.

| Skill | Use it when |
|---|---|
| `board-night` | Host board game nights with teach scripts. Use for groups. |
| `chess-improve` | Improve chess with tactics ladders and game review. Use for club players. |
| `dnd-dm` | Run D and D sessions with prep and improv tools. Use for new DMs. |
| `game-design` | Design board or video games with loops and playtests. Use for prototypes. |
| `go-game` | Learn Go with captures and life-and-death basics. Use for beginners. |
| `poker-basics` | Learn poker fundamentals with bankroll rules. Play responsibly. Use for home games. |
| `puzzles-train` | Train logic with puzzle ladders. Use for fun and interviews. |
| `videogame-optimize` | Tune PC and settings for smooth play. Use for stuttering games. |
