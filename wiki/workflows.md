# Workflows - plays that run skills in order

A workflow is a skill whose job is a sequence: load each step fully, carry outputs forward, stop on red gates.

## `fix-hotfix` (software-build)

Fix bugs with diagnosis, minimal fix, and regression proof. Use for any defect.

Steps: `debugging, test-generator, code-review, pr-create`

## `home-move` (home-life)

Move house from boxes to settled with safety audit. Use when relocating.

Steps: `moving-checklist, declutter-guide, home-safety-review, budget-plan`

## `incident-response` (devops-infra)

Run incidents from alert to verified fix with follow-ups. Use for production incidents.

Steps: `log-triage, debugging, deploy-checklist, meeting-notes`

## `launch-post` (business-ops)

Take a launch post from idea to published with review. Use for launches and announcements.

Steps: `marketing-copy, blog-writer, content-review`

## `onboard-hire` (productivity)

Onboard a new hire to productive in 30 days. Use for every new team member.

Steps: `hiring-interview, onboarding-plan, repo-onboarder, meeting-notes`

## `plan-trip` (travel)

Plan a complete trip from idea to packed bag. Use for any vacation.

Steps: `trip-plan, itinerary-builder, budget-travel, packing-list, travel-safety`

## `publish-newsletter` (creative-media)

Publish a newsletter issue from idea to sent. Use for weekly publishing.

Steps: `newsletter-writer, content-review`

## `research-dossier` (docs-research)

Research any topic into a sourced dossier with recommendation. Use for decisions.

Steps: `tech-research, paper-summarizer, citation-check, report-writing`

## `run-event` (events)

Run an event from idea to toast. Use for parties and celebrations.

Steps: `party-plan, event-budget, toast-speech`

## `ship-feature` (software-build)

Ship a feature from branch to merged PR with tests and review. Use when building anything shippable.

Steps: `git-branch, task-planner, tdd-workflow, test-generator, code-review, pr-create`
