# legal-finance

Organize money and paperwork. General info - confirm big decisions professionally.

| Skill | Type | Use it when |
|---|---|---|
| `budget-plan` | skill | Build a monthly budget from income and spending. Use when money feels chaotic. |
| `contract-reader` | skill | Summarize contracts into obligations, risks, and questions. Use before signing anything. Not legal advice. |
| `credit-score` | skill | Build credit with utilization, history, and disputes. Use for better rates. General info. |
| `debt-payoff` | skill | Kill debt with payoff order and automation. Use when debt lingers. General info. |
| `expense-audit` | skill | Find wasteful subscriptions and spending leaks. Use for quarterly money cleanup. |
| `finance-review` | skill | Run a monthly money review of spending versus budget. Use on the first of each month. |
| `freelance-rate` | skill | Price freelance work from costs and market rates. Use when quoting clients. |
| `invoice-maker` | skill | Create client-ready invoices with tax and payment terms. Use when billing freelance work. |
| `legal-doc-parse` | skill | Extract parties, dates, amounts, and obligations from legal documents into a fact sheet. Use when comparing versions or summarizing a file. |
| `legal-jargon-translate` | skill | Translate legal clauses into plain obligations. Use when a contract paragraph makes no sense. Not legal advice. |
| `money-playbook` | skill | Personal-finance best practices for long-term habits. Use when building money systems. General information, not professional advice. |
| `salary-compare` | skill | Compare job offers on total compensation. Use when evaluating competing offers. |
| `tax-prep-checklist` | skill | Organize documents for tax filing. Use at tax season. General information, confirm with a tax professional. |
