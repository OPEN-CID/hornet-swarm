# frameworks

React, Next.js, Vue, Django, Rails, FastAPI, Spring, Laravel.

| Skill | Type | Use it when |
|---|---|---|
| `django-patterns` | skill | Build Django with apps, ORM, and templates or DRF. Use for Django projects. |
| `fastapi-service` | skill | Build FastAPI services with Pydantic, dependencies, and docs. Use for Python APIs. |
| `laravel-patterns` | skill | Build Laravel with Eloquent, queues, and Blade or Inertia. Use for PHP apps. |
| `nextjs-app` | skill | Build Next.js apps with routing, caching, and server actions. Use for Next.js projects. |
| `rails-patterns` | skill | Build Rails with resources, jobs, and Hotwire. Use for Rails apps. |
| `react-patterns` | skill | Build React with hooks, colocation, and server components. Use for React apps. |
| `spring-boot` | skill | Build Spring Boot services with layers, profiles, and actuators. Use for Java services. |
| `vue-patterns` | skill | Build Vue with composition API, Pinia, and SFC structure. Use for Vue apps. |

Install: Copy-Item -Recurse skills/<name> .agents/skills/ - full file: `skills/<name>/SKILL.md`

Workflows (plays) live on the [workflows](workflows.md) page.
