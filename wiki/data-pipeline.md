# data-pipeline

Move, check, and present data.

| Skill | Use it when |
|---|---|
| `dashboard-design` | Design dashboards that answer decisions. Use for BI and reporting work. |
| `data-doc-parse` | Profile CSVs and API docs into schema and quality notes. Use before building any pipeline. |
| `data-playbook` | Data-engineering best practices for trusted pipelines. Use when setting team standards. |
| `data-quality-check` | Define freshness, schema, and anomaly checks. Use when data breaks trust. |
| `etl-pipeline` | Design extract-transform-load jobs with idempotency and retries. Use when moving data between systems. |
| `pipeline-review` | Review a data pipeline for correctness, cost, and failure modes. Use before productionizing. |
| `query-translate` | Turn business questions into query plans and SQL sketches. Use when stakeholders ask for numbers. |
| `spreadsheet-model` | Build auditable spreadsheet models with checks. Use for financial or ops models. |
| `survey-design` | Write unbiased surveys with analysis plans. Use before collecting responses. |
| `web-scrape-plan` | Plan ethical scraping with rate limits and legal checks. Use when gathering public web data. |
