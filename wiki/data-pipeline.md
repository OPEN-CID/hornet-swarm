# data-pipeline

Move, check, and present data.

| Skill | Type | Use it when |
|---|---|---|
| `dashboard-design` | skill | Design dashboards that answer decisions. Use for BI and reporting work. |
| `data-doc-parse` | skill | Profile CSVs and API docs into schema and quality notes. Use before building any pipeline. |
| `data-playbook` | skill | Data-engineering best practices for trusted pipelines. Use when setting team standards. |
| `data-quality-check` | skill | Define freshness, schema, and anomaly checks. Use when data breaks trust. |
| `etl-pipeline` | skill | Design extract-transform-load jobs with idempotency and retries. Use when moving data between systems. |
| `pipeline-review` | skill | Review a data pipeline for correctness, cost, and failure modes. Use before productionizing. |
| `powerbi-basics` | skill | Build Power BI reports with models and DAX basics. Use for business dashboards. |
| `query-translate` | skill | Turn business questions into query plans and SQL sketches. Use when stakeholders ask for numbers. |
| `spreadsheet-model` | skill | Build auditable spreadsheet models with checks. Use for financial or ops models. |
| `survey-design` | skill | Write unbiased surveys with analysis plans. Use before collecting responses. |
| `web-scrape-plan` | skill | Plan ethical scraping with rate limits and legal checks. Use when gathering public web data. |

Install: Copy-Item -Recurse skills/<name> .agents/skills/ - full file: `skills/<name>/SKILL.md`

Workflows (plays) live on the [workflows](workflows.md) page.
