# leadership

Manage, give feedback, speak, and facilitate.

| Skill | Type | Use it when |
|---|---|---|
| `difficult-firing` | skill | Handle exits legally and humanely with HR. Use with HR guidance only. |
| `feedback-deliver` | skill | Deliver tough feedback with specifics and next steps. Use for performance talks. |
| `manage-first` | skill | Manage your first team with 1:1s and clear expectations. Use for new managers. |
| `meeting-facilitate` | skill | Facilitate meetings that end with decisions. Use for workshops. |
| `one-on-one` | skill | Run 1:1s people value with agendas and career talk. Use weekly. |
| `presentation-design` | skill | Design slides that support, not replace, you. Use for decks. |
| `public-speaking` | skill | Speak confidently with structure and rehearsal. Use before talks. |
| `remote-manage` | skill | Run remote teams with async defaults and trust. Use for distributed teams. |

Install: Copy-Item -Recurse skills/<name> .agents/skills/ - full file: `skills/<name>/SKILL.md`

Workflows (plays) live on the [workflows](workflows.md) page.
