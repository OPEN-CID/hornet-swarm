# leadership

Manage, give feedback, speak, and facilitate.

| Skill | Use it when |
|---|---|
| `difficult-firing` | Handle exits legally and humanely with HR. Use with HR guidance only. |
| `feedback-deliver` | Deliver tough feedback with specifics and next steps. Use for performance talks. |
| `manage-first` | Manage your first team with 1:1s and clear expectations. Use for new managers. |
| `meeting-facilitate` | Facilitate meetings that end with decisions. Use for workshops. |
| `one-on-one` | Run 1:1s people value with agendas and career talk. Use weekly. |
| `presentation-design` | Design slides that support, not replace, you. Use for decks. |
| `public-speaking` | Speak confidently with structure and rehearsal. Use before talks. |
| `remote-manage` | Run remote teams with async defaults and trust. Use for distributed teams. |
