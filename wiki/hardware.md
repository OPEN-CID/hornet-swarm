# hardware

GPUs, PC builds, Pi projects, home servers. Safety first.

| Skill | Type | Use it when |
|---|---|---|
| `amd-gpu` | skill | Set up AMD GPUs with ROCm and compatibility checks. Use for AMD compute or gaming. |
| `arduino-basics` | skill | Build Arduino projects with boards, sensors, and sketches. Use for electronics beginners. |
| `drone-fly` | skill | Fly camera drones legally with sharp shots. Use for aerial photo and video. Follow local rules. |
| `home-server` | skill | Run a home server or NAS with storage, backups, and remote access. Use for self-hosting. |
| `keyboard-build` | skill | Build mechanical keyboards with parts and assembly. Use for custom boards. |
| `nvidia-gpu` | skill | Set up NVIDIA GPUs with drivers, CUDA, and VRAM sizing. Use for ML or gaming rigs. |
| `pc-build` | skill | Build a PC with compatible parts and assembly order. Use for custom desktops. Never open a PSU. |
| `raspberry-pi` | skill | Run Raspberry Pi projects with OS, GPIO, and headless setup. Use for DIY electronics. |

Install: Copy-Item -Recurse skills/<name> .agents/skills/ - full file: `skills/<name>/SKILL.md`
