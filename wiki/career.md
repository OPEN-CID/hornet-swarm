# career

Apply, interview, negotiate, grow.

| Skill | Use it when |
|---|---|
| `application-review` | Pre-submit review of resume and letter against the post. Use before hitting apply. |
| `career-playbook` | Career-growth best practices for steady advancement. Use for yearly planning. |
| `cover-letter` | Write short specific cover letters. Use for each application. |
| `feedback-translate` | Decode vague interview or review feedback into concrete actions. Use after rejections or ratings. |
| `interview-prep` | Run mock interviews with STAR feedback. Use before real interviews. |
| `job-post-parse` | Parse job posts into requirements and match matrix. Use before tailoring an application. |
| `linkedin-optimize` | Rewrite LinkedIn profiles for recruiter search. Use for job hunting. |
| `performance-review` | Write self-reviews with evidence and growth goals. Use at review season. |
| `resume-writer` | Tailor resumes to job posts with measurable impact. Use when applying for jobs. |
| `salary-negotiate` | Plan negotiation scripts with ranges and walk-aways. Use with an offer in hand. |
