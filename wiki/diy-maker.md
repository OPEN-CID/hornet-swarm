# diy-maker

Build and fix things safely with real plans.

| Skill | Use it when |
|---|---|
| `build-review` | Pre-cut review of plans for safety, measurements, and missing steps. Use before any irreversible cut. |
| `car-maintenance` | Track car service with DIY checks and schedules. Use for routine vehicle care. |
| `diy-electrical-safety` | Assess home electrical tasks and know when to call an electrician. Use before any wiring work. Safety first. |
| `diy-plumbing-fix` | Diagnose and fix common leaks and clogs safely. Use for minor plumbing issues. |
| `furniture-assemble` | Guide flat-pack furniture assembly without leftover screws. Use for IKEA-style builds. |
| `gardening-plan` | Plan seasonal vegetable or flower gardens. Use when starting a garden. |
| `home-energy-audit` | Find home energy waste and prioritize fixes. Use to cut utility bills. |
| `material-translate` | Decode lumber grades, fastener codes, and paint labels into what to buy. Use at the hardware store. |
| `plan-parse` | Read build plans and schematics into cut lists and step order. Use before buying materials. |
| `print-3d` | Prepare models for 3D printing with slicer settings. Use when printing parts. |
| `woodworking-plan` | Plan beginner woodworking builds with cut lists. Use for furniture projects. |
| `workshop-playbook` | Workshop safety and tool-care best practices. Use when setting up or leveling up a shop. |
