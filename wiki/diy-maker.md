# diy-maker

Build and fix things safely with real plans.

| Skill | Type | Use it when |
|---|---|---|
| `build-review` | skill | Pre-cut review of plans for safety, measurements, and missing steps. Use before any irreversible cut. |
| `car-maintenance` | skill | Track car service with DIY checks and schedules. Use for routine vehicle care. |
| `deck-build` | skill | Build decks with footings, framing, and boards. Check local codes first. Use for outdoor builds. |
| `diy-electrical-safety` | skill | Assess home electrical tasks and know when to call an electrician. Use before any wiring work. Safety first. |
| `diy-plumbing-fix` | skill | Diagnose and fix common leaks and clogs safely. Use for minor plumbing issues. |
| `furniture-assemble` | skill | Guide flat-pack furniture assembly without leftover screws. Use for IKEA-style builds. |
| `gardening-plan` | skill | Plan seasonal vegetable or flower gardens. Use when starting a garden. |
| `home-energy-audit` | skill | Find home energy waste and prioritize fixes. Use to cut utility bills. |
| `material-translate` | skill | Decode lumber grades, fastener codes, and paint labels into what to buy. Use at the hardware store. |
| `plan-parse` | skill | Read build plans and schematics into cut lists and step order. Use before buying materials. |
| `print-3d` | skill | Prepare models for 3D printing with slicer settings. Use when printing parts. |
| `tiling-guide` | skill | Tile floors and walls with layout, cuts, and grout. Use for bathroom and kitchen jobs. |
| `woodworking-plan` | skill | Plan beginner woodworking builds with cut lists. Use for furniture projects. |
| `workshop-playbook` | skill | Workshop safety and tool-care best practices. Use when setting up or leveling up a shop. |
