# craft

Draw, paint, shoot, knit, sew, and make.

| Skill | Type | Use it when |
|---|---|---|
| `calligraphy-start` | skill | Letter with strokes and exemplar sheets. Use for invitations. |
| `candle-making` | skill | Make candles safely with wax temps and wicks. Use for gifts. Safety first. |
| `drawing-start` | skill | Draw with lines, shapes, and 30-day drills. Use for beginners. |
| `jewelry-start` | skill | Make jewelry with wire and bead basics. Use for first pieces. |
| `knitting-start` | skill | Knit scarves with cast-on and fix ladders. Use for first projects. |
| `origami-start` | skill | Fold with crease patterns and paper picks. Use for gifts and calm. |
| `photo-edit` | skill | Edit photos with light, color, and export presets. Use for consistent looks. |
| `photography-basics` | skill | Shoot manual with exposure triangle and composition. Use for new cameras. |
| `pottery-start` | skill | Start pottery with hand-building and kiln basics. Use for classes. |
| `scrapbook-start` | skill | Preserve memories with layouts and archival safety. Use for albums. |
| `sewing-basics` | skill | Sew with machine setup and first alterations. Use for repairs and gifts. |
| `watercolor-start` | skill | Paint watercolors with washes and paper picks. Use for first paintings. |
