# cloud

Kubernetes, Terraform, AWS, DNS, TLS, and costs.

| Skill | Type | Use it when |
|---|---|---|
| `aws-core` | skill | Learn core AWS with VPC, IAM, and cost guards. Use for first accounts. |
| `azure-basics` | skill | Learn Azure with resource groups, VNets, and cost guards. Use for Microsoft-cloud work. |
| `cost-optimize` | skill | Cut cloud bills with rightsizing and lifecycle rules. Use for surprise invoices. |
| `dns-guide` | skill | Manage DNS with records, TTL, and migration plans. Use for launches and moves. |
| `gcp-basics` | skill | Learn GCP with projects, IAM, and budgets. Use for Google-cloud work. |
| `k8s-basics` | skill | Run workloads on Kubernetes with deployments and probes. Use for first clusters. |
| `monitoring-setup` | skill | Monitor services with golden signals and alert rules. Use before production. |
| `networking-basics` | skill | Understand IPs, DNS, and TLS for debugging. Use for connectivity issues. |
| `oci-basics` | skill | Learn Oracle Cloud with compartments and free-tier limits. Use for OCI work. |
| `ssl-guide` | skill | Ship HTTPS with certs and renewal automation. Use for any site. |
| `terraform-start` | skill | Manage infra as code with state safety. Use for AWS or cloud setup. |
