# cloud

| `cost-optimize` | Cut cloud bills with rightsizing and lifecycle rules. Use for surprise invoices. |
| `dns-guide` | Manage DNS with records, TTL, and migration plans. Use for launches and moves. |

| `monitoring-setup` | Monitor services with golden signals and alert rules. Use before production. |
| `networking-basics` | Understand IPs, DNS, and TLS for debugging. Use for connectivity issues. |
| `ssl-guide` | Ship HTTPS with certs and renewal automation. Use for any site. |
| `terraform-start` | Manage infra as code with state safety. Use for AWS or cloud setup. |
