# medical-health

Organize health information. Info only - always consult a professional.

| Skill | Use it when |
|---|---|
| `fitness-plan` | Build progressive workout plans around goals and limits. Use when starting or fixing a training routine. |
| `health-playbook` | Best-practice playbook for ongoing health routines: meds, activity, sleep, records. Use when building a sustainable health system. |
| `med-care-review` | Review a home care plan for gaps, interactions, and missing follow-ups. Use monthly or after any medication change. Information only; pharmacist confirms. |
| `med-discharge-helper` | Turn discharge papers into a home care checklist. Use after a hospital discharge. |
| `med-jargon-translate` | Translate medical jargon into plain language with a glossary. Use when discharge notes, reports, or prescriptions are hard to understand. Information only. |
| `med-lab-reader` | Explain lab results in plain language with questions to ask. Use when reviewing bloodwork or test reports. Information only. |
| `med-pill-schedule` | Build a daily medication schedule from prescription labels. Use when managing multiple meds. Never changes doses; confirm with pharmacist. |
| `med-record-parse` | Extract medications, doses, and appointments from medical documents into a structured list. Use when organizing prescriptions or visit papers. Never alters doses. |
| `med-symptom-triage` | Organize symptoms into a clear timeline summary for a clinician visit. Use when preparing for a doctor appointment. Information only, never a diagnosis. |
| `mental-reset` | Guide a short stress-reset routine with journaling prompts. Use when stressed. Not therapy; crisis situations need a professional. |
| `nutrition-plan` | Plan balanced meals around budget and restrictions. Use when meal planning for health goals. General information, not medical advice. |
| `sleep-improve` | Audit sleep habits and build an improvement plan. Use for insomnia or fatigue routines. |
