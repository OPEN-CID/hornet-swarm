# docs-research

Understand systems and explain them well.

| Skill | Type | Use it when |
|---|---|---|
| `adr-writer` | skill | Record architecture decisions with context, options, and consequences. Use when choosing frameworks, patterns, or data models. |
| `api-docs` | skill | Write accurate API references with examples from real code. Use when documenting endpoints, SDKs, or modules. |
| `codebase-explorer` | skill | Map unfamiliar codebases to entry points, flows, and ownership. Use when onboarding, scoping work, or finding where to change. |
| `diagram-as-code` | skill | Diagram systems as code with Mermaid and C4 basics. Use for docs that stay current. |
| `readme-writer` | skill | Write README files that onboard in five minutes with setup and usage. Use when creating or overhauling any project README. |
| `research-dossier` | flow | Research any topic into a sourced dossier with recommendation. Use for decisions. |
| `tech-research` | skill | Compare options with evidence and give a justified recommendation. Use when choosing libraries, tools, or approaches. |

Install: Copy-Item -Recurse skills/<name> .agents/skills/ - full file: `skills/<name>/SKILL.md`

Workflows (plays) live on the [workflows](workflows.md) page.
