# docs-research

Understand systems and explain them well.

| Skill | Use it when |
|---|---|
| `adr-writer` | Record architecture decisions with context, options, and consequences. Use when choosing frameworks, patterns, or data models. |
| `api-docs` | Write accurate API references with examples from real code. Use when documenting endpoints, SDKs, or modules. |
| `codebase-explorer` | Map unfamiliar codebases to entry points, flows, and ownership. Use when onboarding, scoping work, or finding where to change. |
| `readme-writer` | Write README files that onboard in five minutes with setup and usage. Use when creating or overhauling any project README. |
| `tech-research` | Compare options with evidence and give a justified recommendation. Use when choosing libraries, tools, or approaches. |
