# business-ops

Validate, sell, hire, and operate.

| Skill | Use it when |
|---|---|
| `biz-jargon-translate` | Translate investor, legal, and finance jargon for founders. Use when term sheets or metrics confuse. |
| `business-plan` | Draft lean business plans with unit economics. Use when pitching or planning. |
| `business-review` | Monthly business health review of revenue, pipeline, and costs. Use on the first Monday monthly. |
| `hiring-interview` | Design structured interviews with scorecards. Use when hiring. |
| `idea-validate` | Stress-test startup ideas with customers and numbers. Use before building anything. |
| `kpi-dashboard` | Define KPIs and dashboard layouts that drive action. Use for team reporting. |
| `marketing-copy` | Write landing pages and ads that convert. Use for launches and campaigns. |
| `onboarding-plan` | Build 30-60-90 onboarding for new hires. Use for every new role. |
| `ops-playbook` | Operating-cadence best practices for calm teams. Use when the team feels chaotic. |
| `pitch-deck` | Outline investor pitch decks slide by slide. Use before fundraising. |
| `proposal-parse` | Extract pricing, terms, and deliverables from vendor proposals into a comparison sheet. Use when choosing vendors. |
| `sales-outreach` | Write personalized cold emails and follow-ups. Use for prospecting. |
| `sop-writer` | Turn tribal knowledge into step-by-step SOPs. Use when processes live in heads. |
| `support-reply` | Draft empathetic customer support responses. Use for tickets and bad reviews. |
