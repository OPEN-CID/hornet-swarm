# business-ops

Validate, sell, hire, and operate.

| Skill | Type | Use it when |
|---|---|---|
| `analytics-basics` | skill | Track analytics with events and key reports. Use for decisions. |
| `biz-jargon-translate` | skill | Translate investor, legal, and finance jargon for founders. Use when term sheets or metrics confuse. |
| `business-plan` | skill | Draft lean business plans with unit economics. Use when pitching or planning. |
| `business-review` | skill | Monthly business health review of revenue, pipeline, and costs. Use on the first Monday monthly. |
| `email-marketing` | skill | Run email marketing with sequences and deliverability. Use for lists. |
| `hiring-interview` | skill | Design structured interviews with scorecards. Use when hiring. |
| `idea-validate` | skill | Stress-test startup ideas with customers and numbers. Use before building anything. |
| `kpi-dashboard` | skill | Define KPIs and dashboard layouts that drive action. Use for team reporting. |
| `launch-post` | flow | Take a launch post from idea to published with review. Use for launches and announcements. |
| `marketing-copy` | skill | Write landing pages and ads that convert. Use for launches and campaigns. |
| `onboarding-plan` | skill | Build 30-60-90 onboarding for new hires. Use for every new role. |
| `ops-playbook` | skill | Operating-cadence best practices for calm teams. Use when the team feels chaotic. |
| `pitch-deck` | skill | Outline investor pitch decks slide by slide. Use before fundraising. |
| `pricing-strategy` | skill | Price products with tiers, anchors, and tests. Use before launches. |
| `proposal-parse` | skill | Extract pricing, terms, and deliverables from vendor proposals into a comparison sheet. Use when choosing vendors. |
| `sales-outreach` | skill | Write personalized cold emails and follow-ups. Use for prospecting. |
| `seo-basics` | skill | Rank with keyword maps and page fixes. Use for organic growth. |
| `sop-writer` | skill | Turn tribal knowledge into step-by-step SOPs. Use when processes live in heads. |
| `support-reply` | skill | Draft empathetic customer support responses. Use for tickets and bad reviews. |

Install: Copy-Item -Recurse skills/<name> .agents/skills/ - full file: `skills/<name>/SKILL.md`

Workflows (plays) live on the [workflows](workflows.md) page.
