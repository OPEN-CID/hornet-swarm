# git-release

Clean history, reviewable PRs, safe releases.

| Skill | Use it when |
|---|---|
| `changelog-release` | Draft release notes and changelogs from merged PRs and tags. Use when preparing any tagged release or version announcement. |
| `git-branch` | Manage clean focused branches with safe sync and naming. Use when starting work, switching context, or cleaning up branches. |
| `git-commit` | Craft conventional commits from diffs. Use when the user asks to commit, write a commit message, or clean up VCS history. |
| `pr-create` | Open focused reviewable pull requests with context and test proof. Use when the branch is ready for review or merge. |
| `version-bump` | Propose correct semver bumps from change types and breaking notes. Use when deciding the next version number before release. |
