# travel

Trips, packing, visas, itineraries, and safety.

| Skill | Use it when |
|---|---|
| `budget-travel` | Cut trip costs with swaps that keep the experience. Use when the trip must cost less. |
| `flight-hacks` | Find cheaper flexible flights with dates, airports, and alerts. Use when flights feel overpriced. |
| `itinerary-builder` | Turn must-sees into a timed daily itinerary with buffers. Use when the destination is decided. |
| `packing-list` | Build a trip-specific packing list by weather, activities, and bag size. Use before any trip. |
| `phrasebook-plan` | Learn 30 survival phrases with pronunciation for a trip. Use two weeks before travel. |
| `road-trip` | Plan a road route with stops, fuel, and overnight breaks. Use for driving holidays. |
| `solo-travel` | Plan a first solo trip with safety nets and social options. Use when traveling alone. |
| `travel-safety` | Build a safety plan with document backup, scams, health, and contacts. Use before unfamiliar destinations. |
| `trip-plan` | Plan a complete trip from budget to bookings with day-by-day flow. Use when starting any vacation or work trip. |
| `visa-prep` | Organize visa and entry requirements with documents and timelines. Use for international travel. |
