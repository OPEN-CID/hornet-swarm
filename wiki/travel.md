# travel

Trips, packing, visas, itineraries, and safety.

| Skill | Type | Use it when |
|---|---|---|
| `budget-travel` | skill | Cut trip costs with swaps that keep the experience. Use when the trip must cost less. |
| `camper-van` | skill | Do camper van trips with rental, routes, and campsites. Use for road adventures. |
| `cruise-guide` | skill | Pick cruises with line, cabin, and port math. Use for cruise holidays. |
| `digital-nomad` | skill | Live abroad as a digital nomad with visas, wifi, and budgets. Use for remote work travel. |
| `flight-book` | skill | Book flights with fare rules, seats, and change policies. Use when buying tickets. |
| `flight-hacks` | skill | Find cheaper flexible flights with dates, airports, and alerts. Use when flights feel overpriced. |
| `hotel-book` | skill | Book hotels with location, cancellation, and loyalty math. Use for stays. |
| `itinerary-builder` | skill | Turn must-sees into a timed daily itinerary with buffers. Use when the destination is decided. |
| `jet-lag-beat` | skill | Beat jet lag with light, sleep, and arrival plans. Use for long flights. |
| `package-book` | skill | Book flight-plus-hotel packages with price checks. Use for bundled holidays. |
| `packing-list` | skill | Build a trip-specific packing list by weather, activities, and bag size. Use before any trip. |
| `phrasebook-plan` | skill | Learn 30 survival phrases with pronunciation for a trip. Use two weeks before travel. |
| `plan-trip` | flow | Plan a complete trip from idea to packed bag. Use for any vacation. |
| `points-miles` | skill | Use points and miles with transfer partners and sweet spots. Use for award travel. |
| `road-trip` | skill | Plan a road route with stops, fuel, and overnight breaks. Use for driving holidays. |
| `solo-travel` | skill | Plan a first solo trip with safety nets and social options. Use when traveling alone. |
| `travel-insurance` | skill | Buy travel insurance with medical and cancellation math. Use before big trips. General info. |
| `travel-photography` | skill | Shoot travel photos with light timing and packing. Use for trip photography. |
| `travel-safety` | skill | Build a safety plan with document backup, scams, health, and contacts. Use before unfamiliar destinations. |
| `trip-plan` | skill | Plan a complete trip from budget to bookings with day-by-day flow. Use when starting any vacation or work trip. |
| `visa-prep` | skill | Organize visa and entry requirements with documents and timelines. Use for international travel. |
