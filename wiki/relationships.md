# relationships

Communicate, repair, befriend, and network.

| Skill | Use it when |
|---|---|
| `apology-guide` | Apologize well with specifics and amends. Use after hurting someone. |
| `boundaries-guide` | Set boundaries kindly with scripts for no and limits. Use when overcommitted. |
| `communication-basics` | Say hard things clearly with I-statements and repair. Use when talks go sideways. |
| `conflict-repair` | Repair after fights with acknowledgment and change plans. Use after any argument. |
| `dating-guide` | Date intentionally with values, safety, and early signals. Use when starting to date. |
| `friendship-build` | Build adult friendships with rituals and follow-ups. Use when feeling disconnected. |
| `marriage-checkin` | Run a weekly couple check-in on money, chores, and affection. Use to stay aligned. |
| `networking-guide` | Network genuinely with follow-ups that help others first. Use for career events. |
