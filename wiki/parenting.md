# parenting

Newborns to teens plus elder care. Info only - consult professionals.

| Skill | Use it when |
|---|---|
| `baby-proof` | Baby-proof rooms with checklists by age. Use before crawling starts. |
| `elder-care` | Organize elder care with needs list, services, and family rota. Use when a parent needs support. |
| `family-budget` | Run a family budget with kid costs and savings goals. Use when money is tight. |
| `grandparent-guide` | Help grandparents bond with routines and boundaries. Use for new grandparents. |
| `homeschool-plan` | Plan a homeschool week with subjects, resources, and records. Use when starting homeschooling. |
| `newborn-care` | Handle feeding, sleep, and soothing in the first weeks with logs. Use for newborns 0-3 months. Info only; pediatrician decides. |
| `screen-time` | Set screen rules that stick with alternatives and timers. Use when screens dominate. |
| `sibling-fights` | Defuse sibling fights with scripts and repair routines. Use for daily battles. |
| `teen-talk` | Talk with teens about school, screens, and friends without lectures. Use when conversations shut down. |
| `toddler-guide` | Manage tantrums and routines for ages 1-3 with calm scripts. Use for toddler chaos. |
