# outdoors

Hike, camp, paddle, and read the wild safely.

| Skill | Type | Use it when |
|---|---|---|
| `camp-cook` | skill | Cook camp meals with one-pot plans and bear-safe storage. Use for overnights. |
| `camping-guide` | skill | Camp comfortably with shelter, sleep, and cook systems. Use for first trips. |
| `climb-safety` | skill | Learn climbing safety basics and when to hire a guide. Use before touching rock. Instruction required. |
| `fishing-basics` | skill | Start fishing with knots, rigs, and local rules. Use for beginners. |
| `hiking-prep` | skill | Plan day hikes with gear, food, and turnaround times. Use before any trail. |
| `kayak-start` | skill | Paddle safely with strokes, rescues, and conditions. Use for flatwater starts. |
| `navigation-map` | skill | Navigate with map, compass, and phone backup. Use when trails are unmarked. |
| `sailing-basics` | skill | Learn sailing with points of sail and docking basics. Use for new sailors. Instruction required. |
| `ski-basics` | skill | Learn skiing with lessons, turns, and safety. Use for first seasons. Lessons required. |
| `surf-start` | skill | Start surfing with pop-ups, reading waves, and lineup rules. Use for beginners. Lessons recommended. |
| `survival-basics` | skill | Learn shelter, water, fire, and signal priorities. Use for backcountry prep. Training recommended. |
| `weather-read` | skill | Read sky and forecasts for go or no-go calls. Use before outdoor days. |
| `wildlife-safety` | skill | Handle bears, snakes, and insects with prevention and response. Use in wild country. |
