# outdoors

Hike, camp, paddle, and read the wild safely.

| Skill | Use it when |
|---|---|
| `camp-cook` | Cook camp meals with one-pot plans and bear-safe storage. Use for overnights. |
| `camping-guide` | Camp comfortably with shelter, sleep, and cook systems. Use for first trips. |
| `climb-safety` | Learn climbing safety basics and when to hire a guide. Use before touching rock. Instruction required. |
| `fishing-basics` | Start fishing with knots, rigs, and local rules. Use for beginners. |
| `hiking-prep` | Plan day hikes with gear, food, and turnaround times. Use before any trail. |
| `kayak-start` | Paddle safely with strokes, rescues, and conditions. Use for flatwater starts. |
| `navigation-map` | Navigate with map, compass, and phone backup. Use when trails are unmarked. |
| `survival-basics` | Learn shelter, water, fire, and signal priorities. Use for backcountry prep. Training recommended. |
| `weather-read` | Read sky and forecasts for go or no-go calls. Use before outdoor days. |
| `wildlife-safety` | Handle bears, snakes, and insects with prevention and response. Use in wild country. |
