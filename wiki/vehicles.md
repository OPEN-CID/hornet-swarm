# vehicles

Buy, inspect, ride, charge, and fix transport.

| Skill | Use it when |
|---|---|
| `bike-repair` | Fix flats, brakes, and gears with a home kit. Use for commuter bikes. |
| `car-buy` | Buy cars with total-cost math and negotiation scripts. Use before dealerships. |
| `ev-guide` | Choose and charge EVs with range math and home setup. Use when going electric. |
| `motorcycle-basics` | Start motorcycling with licensing, gear, and training. Use for new riders. Training required. |
| `used-car-review` | Inspect used cars with a 100-point check before paying. Use before any used purchase. |
| `winter-driving` | Drive winter roads with tires, kits, and skid recovery. Use before snow season. |
