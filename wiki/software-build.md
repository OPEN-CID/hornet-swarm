# software-build

Design, write, fix, and reshape code.

| Skill | Use it when |
|---|---|
| `api-design` | Design clean REST or RPC APIs with resources, schemas, and error contracts. Use when creating or changing any API endpoint or data contract. |
| `api-spec-parse` | Parse OpenAPI specs and docs into client code and test lists. Use when integrating a third-party API. |
| `code-explain` | Translate code into plain-language explanations with flow maps. Use when onboarding or reviewing unfamiliar code. |
| `db-migration` | Write safe reversible database migrations with backfill plans. Use when changing schema, adding indexes, or backfilling data. |
| `debugging` | Diagnose bugs systematically with reproduction, hypothesis, and fix verification. Use when investigating any error, failure, or unexpected behavior. |
| `frontend-component` | Build accessible reusable UI components with props, states, and tests. Use when creating or refactoring any frontend component or page. |
| `refactoring` | Restructure code safely in small behavior-preserving steps. Use when cleaning duplication, renaming, or extracting modules. |
