# saas-tools

Notion, Figma, Slack, Stripe, Shopify and everyday company tools.

| Skill | Type | Use it when |
|---|---|---|
| `etsy-shop` | skill | Sell handmade goods on Etsy with SEO titles and pricing. Use for craft sellers. |
| `figma-basics` | skill | Design in Figma with components, auto-layout, and handoff. Use for UI work. |
| `google-workspace` | skill | Run Google Workspace with Drive, Docs, and admin basics. Use for small teams. |
| `notion-setup` | skill | Organize Notion with databases, templates, and sharing. Use for team or personal wikis. |
| `shopify-start` | skill | Launch a Shopify store with theme, products, and checkout. Use for ecommerce. |
| `slack-guide` | skill | Run Slack with channels, huddles, and notification norms. Use for team chat. |
| `stripe-setup` | skill | Accept payments with Stripe products, webhooks, and test mode. Use for online billing. |
| `zoom-guide` | skill | Host Zoom meetings with settings, recordings, and etiquette. Use for remote meetings. |

Install: Copy-Item -Recurse skills/<name> .agents/skills/ - full file: `skills/<name>/SKILL.md`

Workflows (plays) live on the [workflows](workflows.md) page.
