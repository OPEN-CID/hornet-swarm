# gamedev

Unity, Unreal, Godot, pixel art, audio, publishing, Roblox, Minecraft.

| Skill | Type | Use it when |
|---|---|---|
| `game-audio` | skill | Create game audio with SFX and music loops. Use for game sound. |
| `game-publish` | skill | Release games on Steam or itch.io with page and pricing. Use for launches. |
| `godot-basics` | skill | Build Godot games with nodes, GDScript, and export presets. Use for indie games. |
| `minecraft-mod` | skill | Mod Minecraft with Java mods or datapacks. Use for custom servers and maps. |
| `pixel-art` | skill | Make pixel art sprites, tilesets, and animations. Use for 2D games. |
| `roblox-create` | skill | Create Roblox games with Studio, Lua, and monetization. Use for Roblox creators. |
| `unity-basics` | skill | Build Unity games with scenes, prefabs, and C# scripts. Use for Unity projects. |
| `unreal-basics` | skill | Build Unreal games with Blueprints and actors. Use for Unreal projects. |

Install: Copy-Item -Recurse skills/<name> .agents/skills/ - full file: `skills/<name>/SKILL.md`
