# knowledge

Notes, inbox, calendar, reports, and research.

| Skill | Type | Use it when |

| `calendar-os` | skill | Run your calendar with timeblocks and buffers. Use when days fragment. |
| `data-viz` | skill | Chart data honestly with the right chart and labels. Use for presentations. |
| `email-zero` | skill | Reach inbox zero with triage rules and templates. Use for overflowing inboxes. |
| `note-system` | skill | Build a note system you actually retrieve from. Use when notes go to die. |
| `pkm-tools` | skill | Pick note apps with a migration and backup plan. Use when switching tools. |
| `report-writing` | skill | Write reports that get read with BLUF and appendices. Use for work docs. |
| `research-brief` | skill | Research any topic into a sourced one-pager. Use for decisions. |
| `typing-speed` | skill | Type faster with home-row drills and posture. Use for daily computer work. |
